# TUI 技术文档

TUI 基于 Ink（React），是 runtime 的交互客户端：仪表盘、任务配置、全局设置、日志查看、命令面板与各类覆盖层。动画帧率 110ms，全部样式兼容 16 色终端。

## 布局引擎（layout.ts）

所有尺寸是终端大小的纯函数，resize 即重算，无跨帧状态：

- `frameWidth/frameHeight`：各留一格余量——Windows 控制台末列写入即换行；ink 在输出高度达到终端高度时会整屏清空导致闪烁，少一行可避免。
- 断点：≥76 列双栏（任务/运行记录并列），≥80×24 大字 banner，<40×12 显示"窗口过小"提示。
- 面板：`panelOuterHeight = 内容行 + 3`（边框+标题行）；内容区 = 高度 − banner − footer。
- 行内列宽自适应：任务行（版本/调度）与运行行（时间/时长）随宽度逐列丢弃，名称列有最低宽度。
- 底部栏：按宽度贪心打包按键提示到最多 2 行，footer 高度因此可预测（先算高度再分配内容区）。

## 组件（components.tsx）

- `RenderShell`：精确外尺寸的圆角边框盒，`overflow=hidden` 防内容戳破底边框。
- `RenderBanner`：标题栏。大字模式用 3×5 像素图（半块字符 ▀▄█ 合成）绘制 "Automatic-Task"；小模式单行。两种模式右侧都有脉冲条（蓝色 `━╌` 滑动）、连接状态徽标、时钟。
- 标题动画：正弦波驱动每个字母灰度（`sin(index*0.9 + frame*0.35)`），黑白灰 4 级（whiteBright→white→gray），相邻字母错相形成 2~3 个波峰流动，每帧推进约 1/3 字母。
- `RenderPanel`：带标题与右提示的边框面板，聚焦时边框高亮。
- `RenderScrollBox`：固定行数列表 + 右侧滚动条（`█` 滑块 / `│` 轨道），空行填充保持高度恒定。
- `RenderFooter`：整行边框，按宽度自动换行的按键提示 + 最后一行提示条（错误红色/成功绿色）。
- `RenderTooSmall`：窗口过小时的替代界面（无边框，避免布局损坏）。

## 全屏与终端安全（screen.ts / tui.tsx）

- 进入备用屏幕缓冲（`\x1b[?1049h`），退出时恢复并显示光标。
- 退出守卫：exit/SIGINT/SIGTERM/uncaughtException/unhandledRejection 都会离开备用缓冲；错误输出到 stderr（不在缓冲内，可幸存）。
- resize 清屏：ink 增量绘制依赖行数记录，窗口变窄时物理行数超过记录导致残影；在渲染前注册监听，实际尺寸变化时 `2J[H` 清屏。重复尺寸事件跳过。
- ink 渲染关闭 `patchConsole`（避免闪烁），`exitOnCtrlC` 开启。

## 覆盖层（overlay.tsx + overlays/）

绝对定位卡片，遵循"每行写满内宽"的不透明契约：

- ink 无合成层，未写入的单元格透明；CJK 双宽字形可能跨越卡片左缘造成整行错位。因此覆盖层覆盖帧内全部内部列（左右各留一列给边框），行文本用 `padCells` 补齐。
- 覆盖层不能用 `paddingX`（ink 不写 padding 单元格），内边距由文本自带。
- `RenderOverlayList`：可见行 + 尾部空行填充，保持卡片尺寸。
- 命令面板（`^P` 打开）：模糊搜索输入框（`❯` 提示符）+ 空行 + 结果列表 + 底部按键提示。四项：全局配置、安装任务包、卸载任务包（确认框）、清理全部缓存（确认框，删所有已结束运行的记录、日志与工作区）。
- 文件选择器（命令面板「安装任务包」打开）：目录浏览 + 类型过滤（.atp），模糊搜索过滤，最多 500 项。
- 选项选择器（表单字段 `↵` 打开）：列表选择（select 多选项、overlap 等）。
- 确认框（`y`/`↵` 确认，`n`/`Esc` 取消）。
- Toast：右下角卡片，成功绿色/失败红色，多行自动换行（最多 3 行，4 秒消失）。

## 表单

### 任务配置（task-form.tsx）

基于 `task.schema`（@var 声明）+ `task.get`（当前配置）渲染字段：

- 字段行：定时计划（cron 文本）、并发策略（select）、每个 @var 一行（按类型）。
- 类型化交互：select/boolean 用 `←→` 循环或 `↵` 打开选项选择器；文本字段 `↵` 进入行内输入。
- 密码字段：显示 `•` 掩码；未配置显示"已保存/未设置"，留空保存不覆盖。
- 默认值提示（灰色"（默认 x）"）、必填标记（`*`）。
- 保存：增量 patch（`task.setConfig` 只提交非空项）+ `task.setSchedule`；数字/布尔字段解析校验。
- 状态提示：加载中/保存中/未保存（●）/已同步；说明面板显示当前字段提示——`@var` 行尾注释写了说明就显示说明，否则显示类型与默认值。

### 全局设置（settings-form.tsx）

基于 `app.get` 渲染 app.json 全部字段：Agent（命令/参数/模型）、日志（级别/单文件大小（MB）/保留文件数量）、自动清理日志（天）、自动清理工作区（天）。后两项为 0 表示关闭对应的自动清理。保存走 `app.set` 全量 patch。

## 快捷键

| 页 | 键 | 功能 |
|----|----|------|
| 仪表盘 | ↑↓ | 选择（当前栏） |
| | Tab | 切换任务/运行记录栏 |
| | ↵ | 任务栏：配置页；运行栏：日志页 |
| | e | 运行选中任务 |
| | 空格 | 启用/停用任务 |
| | x | 停止选中运行 |
| | r | 刷新 |
| | ^P | 命令面板 |
| | q | 退出 |
| 配置页/设置页 | ↑↓ | 选择 |
| | ↵ | 编辑/选项 |
| | ←→ | 切换选项 |
| | s | 保存 |
| | r | 刷新 |
| | Esc | 返回 |
| 日志页 | ↑↓/PgUp/PgDn | 滚动 |
| | g/G | 首/末 |
| | r | 刷新 |
| | Esc | 返回 |

界面上没写进按键提示的隐藏键一律不存在：没有 `j/k` vim 别名、没有 `?` 开面板、命令面板里没有 `^P/^N`。改键位时按键提示与 `useInput` 必须同步改。

## 数据流

- `useTui`：连接 runtime、1 秒刷新列表与时钟、110ms 动画帧、事件监听（`run.step.output` 实时追加日志，运行状态事件自动刷新）。
- 日志页取数用 `logs.tail` 带 runId，保证显示选中运行的内容；运行中通过事件实时追加。
- 运行记录行显示运行开始时间（`MM-DD HH:mm:ss`），日志页标题同样附带。
